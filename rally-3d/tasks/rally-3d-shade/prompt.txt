Rally's court pages have a 3D view that traces how much of each venue's courts the trees and buildings shade as the sun moves; today it only runs in the browser with three.js. We want the same numbers on the server to precompute a shade forecast.

Port it to headless Node in this repo: implement `sunPosition` in src/sun.js and `shadeAt` in src/shade.js (src/geometry.js is given). README.md has the scene format and the exact trace; reference/sun.ts and reference/viewer-shade.ts are the current browser implementations. test/shade.test.js has a few cases; run `node --test`. Keep the visible test file as it is.
