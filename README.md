# benchmarks

Small, self-contained coding-agent benchmarks. Each benchmark lives in its own
folder with its own README, runner and committed run records, so it can be
reproduced on its own.

| benchmark | what it tests |
|---|---|
| [**rally-3d**](rally-3d/) | can a coding agent rebuild a real 3D feature — given the browser trace and sun math, or from prose alone? |
| [**agent-overhead**](agent-overhead/) | how much CPU and memory does each coding agent spend on its own, per turn, with the model factored out? |
